# Tech Accessories — E-Commerce Demo

A minimalist, responsive e-commerce website built with **HTML, CSS, and Vanilla JavaScript**.
Designed as a portfolio project to demonstrate clean UI, smooth interactions, and realistic shopping flows.

---

🔗 **Live Demo:** [Open the site](https://erenb1lge.github.io/tech-accessories-ecommerce/)

## ✨ Features

- Responsive layout (desktop & mobile)
- Fixed navigation bar with mobile hamburger menu
- Smooth scrolling navigation
- Product listing with search & sorting
- Product details pages
- Shopping cart using `localStorage`
- Checkout flow (UI demo)
- Order success confirmation
- Featured section as visual showcase (non-clickable, hover animation)

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript (ES Modules)
- LocalStorage (cart state)
- No frameworks, no libraries

## ▶️ How to Run

### Recommended (best)
Use **VS Code Live Server**:
1. Open project folder in VS Code
2. Right-click `index.html`
3. Select **Open with Live Server**

### Alternative
You can open `index.html` directly in the browser,  
but some browsers may restrict ES module imports.
