FAQ

Short answers to the most common questions.

Is this a real store?

No. This project is a front-end portfolio demo built with HTML, CSS, and JavaScript. It focuses on UI quality, UX clarity, and realistic e-commerce flows.

Do you process payments?

No. There are no real payments. Checkout is simulated to demonstrate forms, validation, and order confirmation UI.

Can I add a real backend later?

Yes. The structure is designed so it can be connected to a backend (products API, cart, orders, and authentication) with minimal refactoring.

How can I contact support?

Use the Contact page in this demo to see a clean UI layout for a contact form.
